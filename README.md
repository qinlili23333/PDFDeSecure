## Description ##

An easy-to-use PDF Unlocker. Remove copy-protection from PDF files.  
Modernized on Avalonia with NativeAOT.  

## How To ##

* Select your PDF Protected File (Browse).
* Click 'Unlock' button and Save the Un-Protected PDF File.
